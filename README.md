## 🚀 Pinned Projects

### 1. BuyFlow ERP - 기업 프로세스 ERP 시스템  
**Java, Spring Boot, Spring Security, JPA, Oracle Wallet, Next.js, React, Tailwind CSS, Docker, OCIR, OKE, GitHub Actions**

구매요청부터 승인, 발주, 입고, 검수, 재고 관리까지 이어지는 기업 내부 구매·물류 업무 흐름을 웹 기반으로 구현한 ERP 시스템입니다.

**Role**
- Team Leader / Full Stack / DevOps
- 담당 영역: 대시보드, 품목관리, 구매요청, 승인관리, CI/CD 및 OKE 배포

**What I did**
- Docker, Kubernetes, OKE, OCIR, GitHub Actions 기반 CI/CD 자동 배포 구조 구성
- Next.js App Router 기반 대시보드 화면 구현 및 구매·입고·검수·재고 현황 데이터 연동
- 품목 코드, 품목명, 카테고리, 단위, 단가, 사용 여부를 관리하는 품목 마스터 기능 구현
- 품목 선택 모달을 통해 구매요청 품목을 추가하고 수량·단가 기반 총 금액을 자동 계산하는 흐름 구현
- 구매요청 등록, 목록, 상세, 수정, 삭제, 취소 기능 구현
- 승인 대기, 승인 완료, 반려, 요청 취소 등 상태 기반 업무 제어 구현
- 승인/반려 처리 및 Approval History 기반 승인 이력 관리 구현
- 프론트엔드·백엔드·DB·배포 레포를 분리하여 운영 가능한 프로젝트 구조 구성

**Key Point**
- 단순 CRUD가 아니라 **기준정보 → 구매요청 → 승인/반려 → 발주/입고/검수/재고**로 이어지는 업무 흐름을 구현한 프로젝트
- GitHub Actions에서 Docker Image Build, OCIR Push, OKE Deploy, Rollout Verify까지 연결하여 배포 자동화 경험 확보
- Oracle Wallet 기반 DB 연결과 Kubernetes ConfigMap / Secret 분리로 운영 환경 구성을 경험

🔗 **Repository:**  
- [Frontend](https://github.com/BuyFlow-ERP/frontend-buyflow)  
- [Backend](https://github.com/BuyFlow-ERP/backend-buyflow)  
- [Deploy](https://github.com/BuyFlow-ERP/buyflow-deploy)

- 데이터 분석 결과는 실제 사용자 기능으로 연결될 때 더 큰 가치를 가진다는 점을 배웠습니다.

- Docker, GitHub Actions, OCIR, OKE를 활용하며 코드 변경 이후 배포·검증까지 자동화하는 흐름을 경험했습니다.
- 팀 프로젝트를 통해 역할 분담, 협업, 일정 관리, 배포 책임의 중요성을 배웠습니다.
